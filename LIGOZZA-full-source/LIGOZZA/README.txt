LIGOZZA Modern Ecommerce Website
================================
Open index.html to run the site locally.

Features:
- Multi-page responsive design
- Left-side hamburger quick menu
- Product grid + individual product detail pages
- Working localStorage cart
- Quantity controls and demo checkout
- Generated campaign hero visual
- Self-contained SVG product artwork
- No build step required

To publish: upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel, etc.).
Replace demo contact/payment details before launch.
